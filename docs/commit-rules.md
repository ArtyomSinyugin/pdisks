# Правила создания сообщений к коммитам

По общему правилу коммиты создаются с префиксами 
doc: - в отношении к документации
feat: - в отношении к нововведениям
fix: - когда исправляются ошибки
chore: - когда нужно внести какие-то стандартные изменения, не относящиесяк предыдущим категориям

Если коммит относится исключительно к какому-то внутреннему крейту или крейтам, префикс нужно расширить информацией в скобках с упоминанием крейта или крейтов. Например:
docs(storage-core): add docs about model

После префикса крайне желательно использовать глагол со строчной буквы, что планируется сделать.
